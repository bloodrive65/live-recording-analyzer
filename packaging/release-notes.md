## What's new in 1.3.2

- **Fixed: "Your latest recording" on the Analyzer tab could show old information.** It was only filled in when you opened the tab, and it didn't update during an analysis, so it could say "Still recording" with a tiny file size after the recording had ended. It now updates when a recording stops, every few seconds while the tab is open, and when an analysis starts.
- While an analysis runs, the box says "Analyzing this recording now" so it matches the Live tab.

Includes everything from 1.3.1: the fixed Partial/Limited color-range warning, and the "Where it comes from on your PC" box on each finding.

Update with Settings → Updates → Check for updates now, or download **Live-Recording-Analyzer-Setup-*.exe** below.
