## What's new in 1.4.1

- **Fixed: the desktop shortcut and taskbar pin kept showing the old icon.** Windows saves a copy of each program's icon and kept using the old one. The installer now gives the shortcuts a fresh icon file, updates your taskbar or Start pin if you have one, and tells Windows to refresh its saved icons.
- Sharper icon at desktop size (48 px) and on high-resolution screens.

Includes everything from 1.4.0: the faster window, the analysis time estimate and countdown, the wave progress bar, and the neutral theme.

Update with Settings → Updates → Check for updates now, or download **Live-Recording-Analyzer-Setup-*.exe** below.
