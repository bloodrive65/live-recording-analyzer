Releases

Always get the newest version from the latest release on GitHub. Installers are built automatically from the public source code.

1.4.2

LATESTOctober 2026
  • Fixed: recordings were analyzed even when you didn't ask. Automatic analysis is now off unless you turn it on in Settings → Behavior or in the guided setup.
  • Fixed: two copies of the app could run at once, which caused double notifications and a second window when clicking one. Now only one copy runs; opening the app again or clicking a notification brings up the open window.
  • Bigger progress bar with broader, slower waves and the percentage inside.

1.4.1

October 2026
  • Fixed: the desktop shortcut and taskbar pin could keep showing the old icon, because Windows reused its saved copy. The installer now gives the shortcuts a fresh icon file, updates existing taskbar and Start pins, and tells Windows to refresh its saved icons.
  • Sharper icon at desktop size and on high-resolution screens.
Download 1.4.1

1.4.0

October 2026
  • Faster, smoother window: the window now runs at normal priority. Only the background work (the PC checks and the analysis) runs at low priority. The analysis runs as a separate process, so reading a large recording no longer slows down the menus.
  • No more freezes from sleeping drives: “Your latest recording” is now checked in the background, so a USB or network drive that is spinning up can't freeze the window.
  • Time estimate: the Analyzer tab shows about how long the quick check and the deep scan will take for your latest recording, and a countdown while it runs. The estimate learns from how fast your PC actually is.
  • New progress bar with slow, smooth waves while analyzing.
  • New look: a pixel-art chip icon and a neutral gray theme.
  • Slowness log: if the window ever can't respond for more than a tenth of a second, the moment is written to perf.log in the data folder, so slowness can be measured instead of guessed.
Download 1.4.0

1.3.2

October 2026
  • Fixed: “Your latest recording” on the Analyzer tab could show old information, such as “Still recording” with a tiny file size after the recording had ended. It now updates when a recording stops, while the tab is open, and when an analysis starts.
  • While an analysis runs, the box says “Analyzing this recording now”, matching the Live tab.
Download 1.3.2

1.3.1

October 2026
  • Fixed a false color-range warning: OBS writes “Partial” in its log, but its menus call the same setting “Limited”. The app compared the words literally and reported a mismatch that wasn't real.
  • Every finding shows where it comes from on your PC: the exact menu path, the scene and source involved (read from your OBS log), the current value, and what to change it to.
  • Specific fixes for findings that used to only describe the problem: missing frames, audio gaps, audio/video length differences, frozen or repeated frames, and file resolution, frame rate or color differences.
  • Smarter HDR finding: if the scene you recorded has no screen, window or game capture, it says HDR didn't affect that recording and lists the scenes it would affect.
  • Encoder settings use the same names as OBS's menus.

Reports made with older versions keep their old text. Analyze the recording again to get the new details.

Download 1.3.1

1.3.0

October 2026
  • Analyzer tab: shows your latest recording and analyzes it with one click. The report no longer opens by itself, which caused the window to flicker and minimize.
  • The report stays available: the last result and its Open report button stay on the Analyzer tab, even after a restart, until you analyze again.
  • Online report page: Open report shows the report on this website. The report is stored inside the link, so nothing is uploaded, it works on any device, and Copy link lets you share it. Open saved copy works offline.
  • OBS Reports tab (was Reports): all saved reports, plus analyzing older recordings from any OBS log.
  • Automatic or manual analysis is now a choice in the last step of guided setup.
  • Fixed: the guided-setup question stopped appearing after setup was finished once, even without Remember my choice. It now appears every time unless you tick it.
  • Built-in updater: checks for new versions, shows what's new, and asks before downloading. It then installs and reopens the app. Install 1.3.0 manually once; later versions can update from inside the app.
  • New app icon.
Download 1.3.0

1.2.1

October 2026
  • Fixed: the app could close by itself right when the automatic analysis finished after a recording. Any future error is saved to crash.log in Documents\Live Recording Analyzer, and the app tells you about it the next time it opens.
  • Settings changes are noticed: while watching, if you change something in OBS (for example the encoder Preset), the Advisor lists what changed, what it should do, and when it takes effect.
  • Before/after comparison: after each analyzed recording, the Advisor compares encoding skips and rendering lag with your previous recording and says whether the change helped.
  • A busy video encoder (100%) with no skipped frames is now a quiet note instead of a warning. It only becomes a warning when frames are actually skipped.
Download 1.2.1

1.2.0

October 2026

New name: Live Recording Analyzer (previously “OBS Session Analyzer”), with a new icon.

  • Guided setup: on first launch the app asks whether you'd like help, with a “Remember my choice” option. It checks OBS, the WebSocket connection, the recording drive, the GPU and HDR on this PC.
  • “Check OBS settings” replaces “Run pre-flight check,” and shows progress while it works.
  • Live OBS connection status on the Settings tab (Connected, OBS not running, WebSocket off, or Password rejected) with a Check again button. It updates on its own after you change OBS.
  • More accurate advice: menu paths checked against current OBS. An audio sample-rate difference is no longer a warning, because OBS converts it automatically. It's only flagged if it actually causes delays. Wording now works for any setup.
  • Lighter: new Light resource mode, the app's own CPU and memory shown in the status bar, and lower-priority analysis and deep scans.
  • Port arrows on the Settings tab are now easy to see.
Download 1.2.0
