Problems explained

Every message the app can show, what it really means for your recording, and where the setting lives in OBS. The menu names below are from OBS Studio 30–32. Older versions are very similar.

How the app decides how serious something is: it only shows a warning or critical message when something will visibly or audibly affect your recording. It looks at your actual hardware and settings, not just general rules. Issues that OBS handles on its own are shown as tips, or not shown at all.

Lost frames

Frames skipped due to encoding lag WARNING

What it means: The video encoder (for example NVIDIA NVENC, AMD or Intel) couldn't keep up, so OBS threw frames away. In the file they usually show up as repeated frames, which look like a small hitch.

Does it matter? Yes. Even 0.1% is about one hitch every 17 seconds at 60 fps.

How to fix it:

  • If the message says the video encoder is at its limit, use a faster encoder preset (Settings → Output → Recording → Preset with Output Mode set to Advanced), lower the output resolution or frame rate, or close other programs that use the encoder (another recorder, NVIDIA Instant Replay, or a second OBS).
  • If it says the recording drive was struggling, see Recording drive.
  • If the GPU was at 95–100% from the game, cap the game's frame rate a little below your monitor's refresh rate, or lower a graphics setting. The game is taking all of the GPU's time.

Frames missed due to rendering lag WARNING

What it means: OBS couldn't draw (render) the frame in time, usually because the game was using all of the GPU.

Does it matter? Yes. These frames are missing from the recording.

How to fix it:

  • Cap the game's frame rate (in-game setting, or the NVIDIA/AMD control panel).
  • Run OBS as administrator so Windows gives it GPU priority. Right-click OBS → Run as administrator.
  • Reduce the number of sources and filters in your scene, especially browser sources and heavy filters.

Repeated frames every ~17 seconds WARNING

What it means: The deep scan found a duplicated frame at a steady interval. This almost always means your source runs at 59.94 fps and OBS at 60 fps, or the other way around.

Does it matter? Yes. It causes a regular micro-stutter in the video.

How to fix it:

Make the source and OBS use the same frame rate. See Frame-rate mismatch.

The recording file has stopped growing CRITICAL

What it means: OBS says it's recording, but no new data has reached the file for several seconds.

Does it matter? Yes, badly. The recording may end up cut off or damaged.

How to fix it:

  • Check that the drive is still connected. USB drives and enclosures can disconnect briefly.
  • If the drive is a hard drive, it may have gone to sleep. In Control Panel → Power Options → Change plan settings → Change advanced power settings, set Hard disk → Turn off hard disk after to Never.
  • Stop the recording and start a new one on an internal SSD if the problem continues.

Settings

Frame-rate mismatch between a capture source and OBS WARNING

What it means: A capture card or camera delivers, for example, 59.94 fps while OBS records at 60 fps.

Does it matter? Yes. You get a repeated or dropped frame every ~17 seconds (59.94 vs 60), or worse for bigger gaps.

How to fix it:

Pick one of these:

  1. Double-click the Video Capture Device source → set Resolution/FPS Type to Custom → set FPS to the same value as OBS (for example 60), or choose Match Output FPS.
  2. Or change OBS to match the source: Settings → Video → Common FPS Values → 59.94.

Many consoles and capture cards really output 59.94 fps. If the source is 59.94, setting OBS to 59.94 is the cleanest fix.

Color range is set to Full WARNING

What it means: OBS is writing “Full” range video. Most players, editors and video sites expect “Limited” range.

Does it matter? Usually yes. Full range is often shown with crushed blacks or washed-out colors after upload or in editors.

How to fix it:

Settings → Advanced → Video → Color Range → Limited. Click Apply before recording. Choose Full only if your whole editing chain is set up for it.

Encoder profile is 10-bit but OBS sends 8-bit pictures TIP

What it means: The encoder profile is set to a 10-bit profile (such as main10), while Settings → Advanced → Video → Color Format is an 8-bit format such as NV12.

Does it matter? Not harmful. The file is a little larger, and some older editors, phones and TVs can't play 10-bit files. It doesn't add any color quality.

How to fix it:

  • For normal (SDR) recording: Settings → Output → Recording → Profile → main (Output Mode: Advanced).
  • For real 10-bit or HDR recording, keep main10 and set Settings → Advanced → Video → Color Format → P010. For HDR, also set Color Space → Rec. 2100 (PQ).

The file doesn't match your settings WARNING

What it means: About 25 seconds into a recording, the app opens the file and compares its resolution, frame rate and color settings with OBS.

Does it matter? Yes. You're recording something different from what you intended.

How to fix it:

The message lists exactly which value differs. Stop, fix that setting, and start a new recording. It's quicker than fixing it later.

Capture sources

Windows HDR is on and a screen capture isn't set to SDR TIP

What it means: With Windows HDR on, Display Capture and Window Capture can look dim or washed out in an SDR recording.

Does it matter? Only if you capture your PC screen. Capture cards aren't affected.

How to fix it:

  • Double-click the Display Capture or Window Capture source → tick Force SDR. In Display Capture this appears with the “Windows 10 (1903 and up)” capture method.
  • Or turn off HDR in Windows Settings → System → Display → Use HDR while recording.
  • Game Capture handles HDR games on its own. If an HDR game looks wrong, open its properties and check Color Space at the bottom.

Audio arrived late — OBS added audio buffering WARNING

What it means: A source's audio reached OBS later than expected, so OBS added a delay to keep everything in step.

Does it matter? Sometimes. Audio can be briefly out of sync around that moment, and the delay stays until OBS restarts.

How to fix it:

  • One message when a source first starts is normal. The app only gives device-specific steps when it keeps happening.
  • Plug capture devices straight into a USB port on the PC (rear ports are best), not a hub.
  • If a capture card's sound comes from a separate audio device: double-click the source → untick Use custom audio device, or add the card's sound as its own Audio Input Capture source and mute the video source in the Audio Mixer.
  • Right-click the source → Deactivate, then Activate, or restart OBS between long recordings.

Audio

A device uses a different audio sample rate than OBS (for example 44.1 kHz vs 48 kHz) INFO

What it means: One device reports a different sample rate than OBS.

Does it matter? Normally no. OBS converts (resamples) the audio automatically. The app only warns about this when it also sees audio delays or gaps from that same device during a recording.

How to fix it:

Only if you get a warning about that device:

  • Many capture devices don't have a sample-rate setting in OBS. If the device appears in Windows as a microphone or line-in, set its rate in Windows Settings → System → Sound → (device) → Format, or in Control Panel → Sound → Recording → (device) → Properties → Advanced → Default Format, to 48000 Hz.
  • Your OBS rate is in Settings → Audio → General → Sample Rate. 48 kHz is the standard for video.

Recording drive

Recording drive is stalling / slow writes WARNING

What it means: Windows reports that each write to the recording drive is taking a long time (hundreds of milliseconds instead of a few).

Does it matter? Yes. OBS can absorb short stalls, but long ones cause skipped frames or a stopped file.

How to fix it:

  • Record to an internal SSD (NVMe or SATA) rather than a USB hard drive or network drive, then move files afterward.
  • Pause cloud sync, backups or antivirus scans that use the same drive while recording.
  • For USB drives, plug directly into a rear USB port on the motherboard instead of a hub, and stop Windows from putting the drive to sleep: Control Panel → Power Options → Change plan settings → Change advanced power settings → Hard disk → Turn off hard disk after → Never and USB settings → USB selective suspend setting → Disabled.

Recording drive is running out of space CRITICAL

What it means: Based on how fast the file is growing, the app estimates how many minutes of space are left.

Does it matter? Yes. When the drive fills up, the recording stops.

How to fix it:

  • Free up space, or stop and continue recording on another drive. To change the recording folder, go to Settings → Output → Recording → Recording Path in OBS.

PC and drivers

Graphics driver reset (Windows event) CRITICAL

What it means: Windows logged that the graphics driver stopped responding and recovered.

Does it matter? Yes. This usually causes a freeze or a large gap in the recording.

How to fix it:

  • Update the graphics driver with a clean install.
  • Undo any GPU overclock or undervolt.
  • Check GPU temperature in the report. The app warns when it's high.

USB or disk error (Windows event) WARNING

What it means: Windows logged a USB disconnect, reset, or disk error near the time of a problem.

Does it matter? Yes, if it lines up with skipped frames or a file stall.

How to fix it:

  • Try a different cable or port, preferably a rear motherboard port. Avoid hubs for capture cards and recording drives.
  • Turn off USB selective suspend: Power Options → Change advanced power settings → USB settings.
