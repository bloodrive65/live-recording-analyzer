FAQ & fixes

Windows says “Windows protected your PC.” Is it safe?

That message (Microsoft SmartScreen) appears for apps that aren't digitally signed with a paid certificate. It doesn't mean a virus was found. The app is built automatically on GitHub from the public source code, and you can read exactly what it does. To continue, click More info → Run anyway.

Will it slow down my game or OBS?

It's designed not to. While watching, it:

  • runs at below-normal priority, so games and OBS always come first
  • reads counters Windows already keeps, about once a second. It doesn't capture the screen or hook into games or OBS.
  • only looks at the busiest programs once every few seconds
  • typically uses under 1% CPU and around 100–150 MB of memory (most of that is the window itself)

The status bar shows the app's own CPU and memory use, so you can check it. For even less, choose Settings → Resource use → Light. The deep scan uses more CPU, but only when you start it, and it also runs at low priority.

It says “Not connected” to OBS

The status light on the Settings tab shows the reason:

StatusFix
OBS isn't runningOpen OBS. The app connects within a few seconds.
WebSocket is turned offIn OBS: Tools → WebSocket Server Settings → tick Enable WebSocket server → OK.
Password rejectedIn that same OBS window click Show Connect Info, copy the password, and paste it on the app's Settings tab.
Port not respondingMake sure the port in the app matches the Server Port in OBS (usually 4455). A firewall rarely blocks this, because it's on the same PC.

After changing anything in OBS, click Check again.

I don't get any pop-ups

  • Check Settings → Alerts while you play isn't set to Off.
  • Windows may be hiding them during games. See Pop-ups over games.
  • Pop-ups are limited to one every 30 seconds, except critical ones. Everything is still listed in the Advisor.

I run OBS as administrator. Is that a problem?

No. The app connects to OBS over its WebSocket connection, which works whether or not OBS is running as administrator. You don't need to run Live Recording Analyzer as administrator.

Does it send anything over the internet?

No. There are no accounts, analytics or uploads. It talks only to OBS on your own PC. Reports and session data stay in your Documents folder.

How accurate are the “likely causes”?

The app records what the PC was doing at the second each problem happened: GPU load, video-encoder load, CPU, memory, drive speed, temperature and the busiest programs. It then points to the most likely cause and says how confident it is. Treat these as well-informed clues, not certainties. If a cause keeps repeating across sessions, it's very likely the real one.

Does it work with other recording software?

Live features are made for OBS Studio. The Check a video file only option on the Analyze tab works with any MP4, MKV, MOV, FLV or TS file, wherever it came from.

Live Recording Analyzer is free and runs entirely on your PC.
