Getting started

This guide takes about five minutes. You only need to do it once.

Requirements

  • Windows 10 or Windows 11 (64-bit)
  • OBS Studio 28 or newer. The connection feature it uses is built into OBS 28 and later.
  • About 300 MB of disk space. The app includes FFmpeg, which it uses to check your video files.
  • Any graphics card. NVIDIA cards also report GPU temperature and video-encoder load.

Install

  1. Open the latest release and download Live-Recording-Analyzer-Setup-x.y.z.exe. If you'd rather not install anything, download the Portable zip, extract it, and run Live Recording Analyzer.exe.
  2. Run the installer. If Windows shows “Windows protected your PC,” click More info, then Run anyway. This appears because the app isn't digitally signed yet. More about this.
  3. Choose whether you want a desktop shortcut and whether the app should start with Windows. It installs for your user account only, so it doesn't need administrator rights.

Upgrading from “OBS Session Analyzer” 1.1.0? The new installer replaces it automatically and keeps your settings, sessions and reports.

Guided setup

The first time you open the app, it asks: “Would you like guided setup?”

  • Yes, guide me: a short walkthrough that checks this PC and shows only what needs attention. Recommended if you're not sure what to look for.
  • No, I'll set it up myself: go straight to the app. Everything is also on the Settings tab.
  • Tick Remember my choice if you don't want to be asked again. You can always start it later from Settings → Run guided setup.

Guided setup checks:

Connect to OBS (one-time)

The app works best when it can talk to OBS directly. That lets it see each skipped frame the moment it happens and pause recording when you ask. OBS has this built in. You just have to turn it on:

  1. In OBS, open Tools → WebSocket Server Settings.
  2. Tick Enable WebSocket server. Leave the port at 4455 unless you know you need something else.
  3. Click OK. OBS saves the setting when you close this window.
  4. In Live Recording Analyzer, the connection status turns green and shows Connected to OBS within a few seconds. You don't need to copy the password, because the app reads it from OBS automatically.

Still showing “Not connected”? Click Check again on the Settings tab. If it says the password was rejected, click Show Connect Info in the same OBS window, copy the password and paste it into the app. More fixes

Without this connection the app still works: it reads the OBS log, watches your PC and checks the file. It just can't react the second a frame is skipped, or pause recording for you.

Make sure pop-ups show up over games

Windows can hide notifications while a full-screen game is running. To get alerts while you play:

  1. Open Windows Settings → System → Notifications.
  2. Make sure notifications are on, and that Live Recording Analyzer is allowed in the list of apps.
  3. Under Turn on do not disturb automatically (Windows 11), untick When playing a game, or add Live Recording Analyzer as a priority app.

You can choose which alerts pop up, and whether they play a sound, under Settings → Alerts while you play.

Your first recording

  1. Open OBS first, then Live Recording Analyzer.
  2. Click Check OBS settings. A progress bar shows while it reads OBS, then the results appear in the Advisor. Fix anything marked CRITICAL or WARNING.
  3. Click Start watching, then minimize the window. The app stays in the system tray.
  4. Start recording in OBS and play.
  5. Stop recording. A few seconds later the Advisor says “Analyzing the recording…”, then shows a summary with an Open report button. Everything happens on your PC; nothing is uploaded. The report is saved in Documents\Live Recording Analyzer\Reports and opens in your web browser.
  6. If you changed OBS settings since your previous recording, a second message compares the two (encoding skips and rendering lag) and says whether the change helped.

Update or uninstall

Update: download the newest installer and run it. Your settings, sessions and reports stay in Documents\Live Recording Analyzer.

Uninstall: go to Windows Settings → Apps → Installed apps → Live Recording Analyzer → Uninstall. Your reports in Documents are kept, so delete that folder too if you don't want them.
